## 🧪 Features
- **Molecular Visualization**: 2D chemical structure rendering (RDKit) and interactive 3D conformer viewer (py3Dmol).
- **Physicochemical Properties**: Real-time calculation of 21 molecular descriptors (MW, LogP, TPSA, HBD, HBA, rotatable bonds, etc.).
- **Structure-Property Comparison**: Multi-molecule comparison table with interactive property charting and Lipinski Rule of 5 evaluation.
- **Advanced Tools**: Cryptographic chemical hashing (SHA-256, InChIKey), QED drug-likeness scoring, Bemis-Murcko scaffold extraction, and Tanimoto similarity search.
- **10-Page Comprehensive PDF Report**: Automated institutional student laboratory report generation with structures, data matrices, and faculty sign-off blocks.
